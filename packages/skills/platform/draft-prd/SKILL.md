# Draft PRD

Generate a PRD from the Issue, brainstorm report, project business skills, and repository signals.

Required sections:

- Background.
- Goals and non-goals.
- User stories.
- Acceptance criteria.
- Risks and unknowns.
- Task type.
- Complexity score.
- Human review decision.

Set `requiresHumanReview=true` for security, permissions, payments, destructive data changes, unclear acceptance criteria, or broad cross-module changes.
