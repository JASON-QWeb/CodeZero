# Agentic Code Search

Do not read the whole repository. Build search hypotheses, run hybrid search, inspect evidence snippets, then stop when evidence is sufficient.

Use:

- Path search.
- Keyword search.
- Symbol search.
- Semantic search.
- History search.
- Project business skill search.

Output a ContextPack with relevant files, evidence, tests, non-relevant areas, and open questions.
