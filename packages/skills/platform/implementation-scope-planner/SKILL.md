# Implementation Scope Planner

Fill the implementation scope section inside the single PRD/Plan document.

The scope must declare:

- Files to read.
- Files expected to change.
- Tests to add or update.
- Commands to run.
- Explicit non-goals.
- Risk notes.

If implementation needs files outside the ContextPack, request another search pass before widening the scope.
