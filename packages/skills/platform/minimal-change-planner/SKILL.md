# Minimal Change Planner

Create an implementation plan that modifies only what the PRD requires.

The plan must declare:

- Files to read.
- Files expected to change.
- Tests to add or update.
- Commands to run.
- Explicit non-goals.
- Risk notes.

If implementation needs files outside the ContextPack, request another search pass.
