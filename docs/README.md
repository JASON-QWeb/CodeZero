## 维护规则

- 新增 docs 文档默认使用中文。
- README 保持中英文两份：`README.md` 为默认中文入口，`README.en.md` 为英文版。
- 计划类、阶段性方案类文档完成后放入 `docs/archive/`。
- 当前入口文档只描述已经落地或正在维护的架构，避免混入旧运行时假设。
